# Recompensas — Uniformes Escolares (Espaço Livre / Jundiaí)

Documento vivo. Mecânicas de prêmio e prova de conclusão.

Complementa [`modelo-de-negocio.md`](./modelo-de-negocio.md). Em conflito com o PRD antigo (`site`), **modelo + este arquivo + `fase-voucher.md` + `etiquetas-qr-decisoes.md` prevalecem**.

Última atualização: 2026-08-11 (extraído do modelo de negócio)

---

## 1. Fase A — Pré-voucher (doação)

- **2 doações concluídas para 2 receptores diferentes** → **1 peça nova** da operação.
- Contagem só com pares distintos (anti-colusão em `modelo-de-negocio.md` §4.3).
- SKU da peça nova: em aberto (sugestão: camiseta curva A no tamanho do filho).

---

## 2. Fase B — Com voucher

- Quem **compra o kit no site** e **doa 1 peça** → **camiseta a mais**.
- Contagem **separada** da Fase A (não acumular dois brindes no mesmo placar).
- Mesmas regras de par / celular / (recomendado) anti-reciprocidade.

> **Não construir antes de ler o edital.** Brinde condicionado à compra com crédito público é
> vantagem econômica atrelada ao uso do voucher — o tipo de mecânica que os programas costumam
> restringir. Vale a mesma ressalva para a indicação premiada aplicada a compras com crédito.
>
> **Substituto seguro:** valor embutido no produto e no serviço em vez de peça de brinde —
> etiqueta com nome inclusa, troca de tamanho garantida sem fila, entrega no bairro, reposição
> rápida. Mais barato que camiseta grátis e impossível de enquadrar como aliciamento.

Contexto operacional da fase: [`fase-voucher.md`](./fase-voucher.md).

---

## 3. Prova de “doação concluída”

Em aberto. Recomendação de lançamento:

- **PIN de entrega** (receptor mostra código; doador confirma no ato) +
- resgate da peça nova com **atraso curto** (ex.: 3–7 dias sem disputa) +
- **teto** (ex.: 1 peça nova / CPF / 90 dias) enquanto a base é pequena.

Foto no anúncio valida a **oferta**, não a entrega.

---

## 4. Indicação por link (placar separado da doação)

Objetivo: escala de **compras** via boca a boca. Cada pessoa com conta pode ter um link; quem compra pelo link de alguém também passa a ter o próprio.

| Regra | Decisão |
|-------|---------|
| Quem ganha link (lançamento) | **Todos** com conta (comprou, doou, recebeu ou pediu etiqueta) — prioriza escala |
| Restrição futura | Pode passar a liberar link **só para quem comprou** |
| Cadeia | Indicado que **compra** ganha o **próprio** link (não herda o do padrinho) |
| O que conta | Valor de compras **atribuídas** ao link (não “número de pessoas” puro) |
| Meta para prêmio | ≈ **R$ 350** em valor atribuído acumulado → **1 camiseta** |
| Prêmio | **1 camiseta** (SKU alinhado ao 2→1 quando fechado) |
| Separação | Placar de indicação **≠** placar de doação (Fase A/B); não misturar |
| Janela de atribuição | Entrar pelo link e comprar **depois** ainda conta (mín. **3 dias**; cookie/código no checkout) |
| Quando o crédito vira “válido” | Só **depois** do prazo de cancelamento / devolução (sem estorno) |
| Estorno / cancelamento | Remove ou não libera o valor daquela compra no placar do indicador |

**Fluxo resumido**

1. Conta criada → recebe link de indicação (fase ampla).
2. Terceiro abre o link → atribuição fica salva (≥ 3 dias).
3. Terceiro compra → valor entra como **pendente** no placar do dono do link.
4. Passou o prazo de devolução/cancelamento sem estorno → valor vira **confirmado**.
5. Soma confirmada ≥ ≈ R$ 350 → dono do link pode resgatar **1 camiseta**.
6. Quem comprou (passo 3) já tem (ou ativa) o **próprio** link para repetir o ciclo.

---

## 5. Em aberto nesta mecânica

1. Fechar prova de conclusão (PIN + atraso + teto vs. outra combinação).
2. SKU da “peça nova” do 2→1 (sugestão: camiseta curva A no tamanho do filho).
3. Indicação: teto de camisetas por CPF/período; se R$ 350 é faixa repetível (700 → 2ª camiseta) ou só 1ª vez; prazo exato de devolução alinhado ao checkout; TTL do cookie além dos 3 dias mínimos.
4. Depois do lançamento: avaliar restringir link só a quem comprou.
5. Fase B (kit + doar → camiseta): só após ler o edital — ver também `fase-voucher.md`.

**Resolvido em ago/2026:** regras base de indicação por link (valor ≈ R$ 350 → camiseta; placar separado; crédito pós-devolução; atribuição ≥ 3 dias; link amplo no início).
